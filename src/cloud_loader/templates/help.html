Documentation & Help

Learn how to use Cloud-Loader and find answers to common questions.

Quick Start Guide

What is Cloud-Loader?

Cloud-Loader is a utility service for AI assistants like Claude Code, OpenClaw, and Codex. It helps you seamlessly migrate configurations between environments, and acts as a storage hub for shared markdown files, skills, and prompts.

Installing the Skill

To get started easily from your terminal, we recommend installing the Cloud-Loader skill directly into your AI assistant. Run the following command:

curl -s {{ base_url }}/skills/loader-land-skill -o loader-land.md

Place the file in your assistant's commands or skills folder (e.g., ~/.claude/commands/).

MD Storage vs. Migration

  • MD Storage: Ideal for storing markdown documents publicly and permanently. Perfect for sharing prompts or code templates.
  • Migration: For packing entire agent configurations (including JSON settings and plugins) into a secure, password-protected ZIP archive that expires after a short period.

Frequently Asked Questions

Are my migration backups secure?

Yes. Your backups are packaged into a password-protected ZIP archive directly on your local machine before being uploaded. The server never knows your password and cannot inspect the contents. Furthermore, backup files are automatically deleted after a specified expiry time (default 24 hours).

Are MD Storage files private?

No. MD Storage is designed for public sharing. Anyone with the link or file code can view the content. Please do not store API keys, passwords, or sensitive personal information in MD Storage.

Which AI Assistants are supported?

Cloud-Loader natively supports configuration migrations for Claude Code, OpenClaw (Moltbot), and Codex. However, it can back up any arbitrary configuration folder if you specify the path.

How do I access the raw API?

If you're accessing the service from an AI agent via the terminal (like `curl`), the server will automatically detect your user-agent and return the raw Markdown API documentation.
